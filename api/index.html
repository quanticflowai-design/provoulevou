API do Lojista

Provou Levou · leitura dos dados do provador, dos disparos e dos pedidos com a atribuição já calculada. Versão 1 — 23/10/2026.

Acesso

Todas as chamadas são GET (ou POST com JSON) para:

https://quantic-supabase.k5jwra.easypanel.host/rest/v1/rpc/<endpoint>

Envie sempre:

  • Header apikey com a chave pública abaixo (é a mesma para todas as lojas, só libera o acesso ao servidor):

  • Parâmetro p_chave com a chave da sua loja (começa com plk_live_, enviada à parte pelo Provou Levou). É ela que identifica a loja: guarde como senha.

Parâmetros de período (todos os endpoints): p_inicio e p_fim no formato AAAA-MM-DD, dias no horário de Brasília, inclusive. Sem eles, vêm os últimos 30 dias.

Paginação: p_limite (padrão 1000, máximo 5000) e p_offset. Formato: JSON por padrão; para CSV envie o header Accept: text/csv.

GETpl_api_resumo

Uma linha por dia com os números do painel. O jeito mais simples de alimentar a planilha.

curl "https://quantic-supabase.k5jwra.easypanel.host/rest/v1/rpc/pl_api_resumo?p_chave=SUA_CHAVE&p_inicio=2026-10-01&p_fim=2026-10-31" \
  -H "apikey: CHAVE_PUBLICA" -H "Accept: text/csv"
CampoO que é
diaData (Brasília)
pedidos_pagos / faturamentoTodos os pedidos pagos da loja no dia
pedidos_pos_prova / faturamento_pos_provaPedidos de clientes que usaram o provador antes de comprar (mesmo telefone), sem limite de tempo
faturamento_pos_prova_24hIdem, só quando a última prova foi até 24 h antes do pedido
faturamento_pos_prova_7dIdem, até 7 dias
pedidos_recuperados_disparo / faturamento_recuperado_disparoPedidos de quem recebeu (entregue ou lida) uma mensagem de WhatsApp da loja até 30 dias antes
provas / clientes_que_provaramProvas feitas no dia e telefones distintos
disparos_enviados / disparos_entreguesMensagens de campanha e automação enviadas no dia e quantas foram entregues ou lidas
Um mesmo pedido pode estar em pós-prova e em recuperado por disparo ao mesmo tempo: as duas colunas não devem ser somadas. Para modelos de atribuição próprios, use o endpoint de pedidos, que traz os tempos de cada contato.

GETpl_api_pedidos

Cada pedido da loja com a jornada no Provou Levou. Use para montar a sua própria janela ou ponderação de atribuição.

Parâmetro extra: p_so_pagos (padrão true; false traz todos os status).

CampoO que é
pedido_id, data, valor, status, pagoDados do pedido na plataforma da loja
cliente_nome, cliente_email, telefoneCliente (telefone só com dígitos)
provou_antesO cliente usou o provador antes desse pedido
primeira_prova / ultima_provaData da primeira e da última prova antes do pedido
horas_desde_ultima_provaTempo entre a última prova e o pedido, em horas
ultimo_produto_provadoProduto da última prova
recuperado_disparoRecebeu mensagem entregue ou lida até 30 dias antes do pedido
ultimo_disparo / ultimo_disparo_tipo / dias_desde_ultimo_disparoA mensagem mais recente antes do pedido (tipo: campanha, automacao ou individual)

GETpl_api_provas

Cada prova feita no provador: prova_id, data, telefone, nome, email, produto, produto_url. A produto_url mantém os parâmetros de campanha da visita (gclid, utm…), útil para cruzar com a mídia.

GETpl_api_disparos

Cada mensagem de WhatsApp enviada: disparo_id, data, telefone, tipo, template, status, erro. Status: sent, delivered, read, failed.

Google Sheets (Apps Script)

Na planilha: Extensões → Apps Script, cole o código, troque a chave e rode atualizarResumo. Para atualizar sozinho, crie um acionador diário.

const URL = 'https://quantic-supabase.k5jwra.easypanel.host/rest/v1/rpc/';
const PUBLICA = 'COLE_A_CHAVE_PUBLICA';
const CHAVE = 'COLE_A_CHAVE_DA_LOJA';

function buscar(endpoint, inicio, fim) {
  const url = URL + endpoint + '?p_chave=' + encodeURIComponent(CHAVE) + '&p_inicio=' + inicio + '&p_fim=' + fim + '&p_limite=5000';
  const r = UrlFetchApp.fetch(url, { headers: { apikey: PUBLICA, Accept: 'text/csv' }, muteHttpExceptions: true });
  if (r.getResponseCode() !== 200) throw new Error(r.getContentText());
  return Utilities.parseCsv(r.getContentText());
}

function atualizarResumo() {
  const hoje = new Date(), ini = new Date(hoje.getFullYear(), hoje.getMonth(), 1);
  const f = d => Utilities.formatDate(d, 'America/Sao_Paulo', 'yyyy-MM-dd');
  const linhas = buscar('pl_api_resumo', f(ini), f(hoje));
  const aba = SpreadsheetApp.getActive().getSheetByName('Provou Levou') || SpreadsheetApp.getActive().insertSheet('Provou Levou');
  aba.clearContents();
  aba.getRange(1, 1, linhas.length, linhas[0].length).setValues(linhas);
}
